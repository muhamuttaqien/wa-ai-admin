# AI Intensive Bootcamp

Source basis: current official specialist pages on aiforindonesia.com for Machine Learning, Computer Vision, and Natural Language Processing, reviewed 2026-10-03. Internal program clarification: current program duration is 12 weeks / 3 months.

## Program overview
AI Intensive Bootcamp is an intensive 12-week / 3-month learning program from Indonesia AI (PT. Teknologi Artifisial Indonesia) designed to help participants build practical AI skills from fundamentals through advanced topics, complete real-world projects, develop a professional portfolio, and prepare for AI-related careers.

The program combines live classes, theory, practical exercises, project work, mentor discussion, learning evaluation, and career preparation.

## Who the program is for
The program can be followed by participants from IT and non-IT backgrounds. Relevant audiences include:
- beginners who want to learn AI from zero
- fresh graduates
- university students and academics
- professionals who want to upskill
- career switchers
- people who want practical AI skills even if they do not intend to become AI engineers
- people interested in building AI projects, portfolios, research, products, or startups

Participants do not need prior programming experience. The program starts with Bootcamp Preparation, where Python Programming is introduced from zero.

## Current specialist tracks
There are three specialist tracks:
- Machine Learning Specialist
- Computer Vision Specialist
- Natural Language Processing Specialist

Each track shares foundational AI, Machine Learning, Deep Learning, project, deployment/MLOps, and career-preparation components, then develops track-specific competencies.
